SteamCore PRO 1.3.0

November 24, 2026

Steam without the online subsystem​

  • The SteamCoreShared module now initializes Steam, so the SteamCore online subsystem is optional for clients.
  • Use Initialize Steam Without Online Subsystem (bInitSteamWithoutOnlineSubsystem) to enable this mode.
  • Dedicated servers still use the online subsystem to log on to Steam.
  • Pass -nosteamcore to skip Steam initialization.
  • The Steam overlay also works in this mode.

Project settings​

  • SteamCore settings are back under Project Settings > Game > SteamCore.
  • A new Setup section shows the client status, plugin and Steamworks SDK versions, and the path the Steamworks libraries load from. It also links to the docs and the app’s Steamworks page.
  • The setup checks have Fix buttons for Steam initialization and for setting DefaultPlatformService to SteamCore.
  • Apply Recommended Settings preserves existing App IDs when writing the recommended configuration.
  • The level editor toolbar now has a SteamCore button.
  • Import Achievements and Import Stats download Steamworks definitions into DT_SteamAchievements and DT_SteamStats under /Game/SteamCore.
  • In non-shipping builds, run showdebug steamcore to display Steam status on screen.

Blueprint nodes​

  • Added Get Stat, Set Stat, and Get User Stat.
  • Added typed nodes for getting and setting lobby and lobby member data, as well as Make Session Setting and Get Session Setting.
  • Added Bind Steam Callback nodes.
  • After an import, the name pins on User Stats nodes offer the imported names in a dropdown.
  • Game Server Item now exposes Had Successful Response. Server browsers can use it to hide or flag servers that did not answer the details query.

SteamCore PRO 1.2.0

November 17, 2026

General​

  • Added the Microphone Level Meter, with nodes to create, start, and stop the meter, read its level and peak amplitude, check its active state, and get the device name.
  • Added nodes to get and set microphone input gain.
  • Protected the microphone device list against concurrent access and stopped clearing it on world startup.
  • Moved the Get Available Audio Input Devices delegate to the game thread.
  • Corrected the log format for 64-bit Steam IDs.

SteamCore PRO 1.1.11

October 18, 2026

General​

  • Fixed async node leaks when the online subsystem is unavailable.
  • Leaderboard reads and writes now finish when the requested leaderboard cannot be found.
  • Async callbacks skip destroyed objects.
  • Resolved deprecation warnings on Unreal Engine 5.3 and newer.

Matchmaking and multiplayer​

  • A new server list, ping, or rules request cancels the previous request.
  • Server list requests finish one second after Steam completes the refresh, without waiting for the timeout.

Dedicated servers​

  • Fixed callback registration for affected game server interfaces so their callbacks fire on dedicated servers.

Removed​

  • Removed the legacy SteamCoreNetDriver.

SteamCore PRO 1.1.7

August 14, 2026

GENERAL​

  • Updated to Steamworks SDK version 1.65

v1.65 23th July 2026​

Steam Machine, Steam Frame and Steam Deck:

  • Removed ISteamUtils::IsRunningOnSteamDeck(). Please use other feature specific methods below.
  • Added ISteamUtils::IsRunningOnSteamHardware() which returns ESteamHardwareType. Use this call for analytics, support or diagnostic purposes. For functional decisions, see other SDK calls.
  • Added ISteamUtils::GetSteamHardwareDefaultConfig() to help choose default game settings (video and other) that you have tuned for specific Steam hardware. It also enables changing your default game settings on future Steam hardware without needing to recompile your game.
  • Added ISteamUtils::IsRunningUnderProton() to determine if your game is running under the Proton compatibility layer on Linux.
  • ISteamUtils contains other pre-existing methods that may be useful when replacing IsRunningOnSteamDeck(), such as ISteamUtils::IsSteamInBigPictureMode() and ISteamUtils::IsSteamRunningInVR().

ISteamApps:

  • Added SetGamePerformanceSetting() and SetGameRenderResolution() methods so a game can report to Steam servers what the relative performance settings and game resolution are set to for the given user. This data will be included with anonymous framerate data if the user has opted into sharing that.

ISteamUGC – Added options for querying UGC (sorted in descending order):

  • k_EUGCQuery_RankedByNumParentItems – how many items depend on this item (if it isn’t a collection)
  • k_EUGCRankedByNumParentCollections – how many collections contain this item

Steam Input:

  • Added Switch 2, Steam Controller and Steam Frame Controller action origin enum values

ISteamMatchmakingServers:

  • Added ISteamMatchmakingServers::ServerFriends() to get a list of friends that have recently played on a specific server
  • Added “popularamongfriends” filter option to retrieve a set of servers that the user’s friends commonly play on
