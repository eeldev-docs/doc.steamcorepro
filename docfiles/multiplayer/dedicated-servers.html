Dedicated Server

TIP

This Example has a Video Tutorial that you can find here: Related Video

Follow these pages in order to set up a dedicated server with SteamCore PRO:

  1. Introduction: requirements, ports and firewall.
  2. DefaultEngine.ini: the configuration for the server and the clients.
  3. Steamworks Settings: the game server version in Steamworks.
  4. Initializing: creating the session and the steamclient libraries.
  5. Launching a Dedicated Server: launch parameters and ports.
  6. Finding the Server: server lists and server browsers.
  7. Connecting to a Dedicated Server: joining the server from a client.
