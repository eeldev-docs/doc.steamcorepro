## **SESSIONS**

- It’s now possible to set a **Session Password** when creating a session
- Added a new node “Join SteamCore PRO Session” that allows the user to enter a **session password**
- Added a “Join Fail Reason” string that returns incorrect password if the password is incorrect for the selected session
- [Created a documentation for this](<https://steamcore-pro.eeldev.com/docfiles/multiplayer/session_password>)
