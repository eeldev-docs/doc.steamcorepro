## **GENERAL**

- Added option to automatically copy steam client dlls when packaging a **Windows Dedicated Server** on a Windows Platform<br />
  *This option will attempt to locate Steam Client dlls and copy them to the packaging location removing the need to manually find and copy these files to the packaged server*.<br />
  Steam Client must be installed

[![](<./01-screenshot-2023-07-17-174613.png>)](<./01-screenshot-2023-07-17-174613.png>)

- Added options for overriding console variables **net.MinHandshakeVersion** and **net.CurrentHandshakeVersion** that are causing steam session issues in UE 5.x
