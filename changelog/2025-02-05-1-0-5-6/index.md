## **GENERAL**

- Updated to Steamworks SDK 1.61

## **SESSIONS**

- It’s now possible to get the current (or latest) player joined lobby using the new function “**Get Last Joined Lobby Id**“
- Added a function to list all joined lobby ids “**Get Joined Lobby Ids**“
