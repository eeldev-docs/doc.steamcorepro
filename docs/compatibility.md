# Compatibility

## Supported Versions

The latest version of SteamCore PRO is built against **Steamworks SDK 1.65**. Which Unreal Engine versions are available depends on where you purchased the plugin:

| Store | Unreal Engine Versions | Steamworks SDK |
|---|---|---|
| [Fab Marketplace](./purchase-plugin.md#fab-marketplace) | 5.6, 5.7, 5.8 | 1.65 |
| [Gumroad](./purchase-plugin.md#gumroad) | 4.27, 5.0 – 5.8 | 1.65 |

:::info Older Engine Versions
If you are using an engine version older than 5.6, purchase the plugin through [Gumroad](./purchase-plugin.md#gumroad), which provides the latest plugin version and Steamworks SDK for all engine versions from 4.27 to 5.8.
:::

## Supported Platforms

- Windows (Win64)
- Linux
- Mac

## Steamworks SDK

The Steamworks SDK is included with the plugin, you do not need to download it separately. The plugin's Blueprint nodes follow the [official Steamworks API](https://partner.steamgames.com/doc/api), so the Steamworks documentation for SDK 1.65 applies.
